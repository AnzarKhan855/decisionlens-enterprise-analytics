## Reporting a Vulnerability

We take the security of DecisionLens and enterprise business data seriously.

If you discover a security vulnerability, please **DO NOT** create a public GitHub issue.

Instead, please send a detailed report to:
**security@decisionlens.io**

Include the following information:
1. Description of the vulnerability and attack vector.
2. Steps to reproduce or proof-of-concept payload.
3. Potential impact on confidentiality, integrity, or availability.
4. Proposed remediation or mitigation (if known).

### Our Commitment
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide a timeline for investigation and patching.
- We will coordinate public disclosure after a patch has been released.
